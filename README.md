# ArtRooomM Firmenbuch

Handy-App für das ArtRooomM-Firmenbuch (Aufträge, Ausgaben, Übersicht) – läuft unter
https://michaelb297-blip.github.io/artroomm/

- Daten: Firebase (Projekt `artrooomm-e4e98`, Firestore Frankfurt), Zugriff nur für freigeschaltete E-Mail-Adressen (siehe `firestore.rules`).
- Excel-Abgleich: `Firmenbuch_ArtRooomM_App.xlsx` im OneDrive, über Microsoft Graph (App-Registrierung „ArtRooomM“, nur persönliche Konten).
- Auf dem iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
